# Ephemeris raster icons

These compact PNGs are local copies of the installed AdwaitaLegacy 22px icon
theme, selected to keep Ephemeris widget chrome reliable when the active icon
theme does not expose a requested symbolic name to Quickshell.

Serpantinum itself primarily uses Nerd Font glyphs; its installed PNG assets are
full-screen guide previews rather than reusable widget icons. Astralith therefore
uses portable raster controls here and reads Serpantinum's wallpaper-picker PNG
cache dynamically instead of copying transient preview files into the suite.
