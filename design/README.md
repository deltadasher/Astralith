# Astralith design studies

This directory preserves dormant identity and interaction experiments that are
not imported by `shell.qml`, registered in a `qmldir`, or shipped as active
runtime components.

`concepts/WabiSabiBlackHole.qml` is the first code-native study for Astralith's
eventual black-hole mark. Its imperfect geometry is intentionally retained as
a starting point rather than presented as finished artwork.
